Sobre mí

¡Hola, Soy Natalia Magalí Hipólito!. Este sitio forma parte de un proyecto de desarrollo web realizado para aprender a crear y diseñar páginas utilizando HTML y CSS.

Me interesa aprender a crear sitios web que sean simples, ordenados y agradables de visitar. En este proyecto también pude experimentar con imágenes, enlaces, colores y diferentes estructuras de una página.

En este proyecto aprendí

  • A crear páginas utilizando HTML.
  • A utilizar CSS para diseñar el sitio.
  • A insertar imágenes.
  • A crear enlaces entre páginas.
